# Higgsfield Commercial Director — custom companion skill

This is a custom *planning* skill to complement Higgsfield's official agent skills. It does not replace them, nor does downloading this ZIP install it into ChatGPT or authenticate Higgsfield.

Official skills: https://github.com/higgsfield-ai/skills
Official recommended install for your own Codex-compatible agent environment:

```bash
npx skills add higgsfield-ai/skills
```

Review upstream code and command prompts before executing installers or granting authentication. In agents that support project-local Markdown skills, place this custom folder in the appropriate local skills directory (for Codex, commonly `.agents/skills/`) or load SKILL.md as agent guidance; check your installed Codex version's conventions.
